# Interface work: pick interface skills

`ailv-ui-index` (Interface work: pick interface skills): Your interface skills each do one job — never read them all. New screen or page → ailv-ui-shell, ailv-ui-tokens, ailv-ui-seo. New interactive piece (typing, dragging, live numbers) → ailv-ui-framework as well. Charts and graphs → ailv-ui-charts plus ailv-ui-chart-twin for the machine twin. Known widget (table, wizard, combo, calendar, modal, feed, kanban, editor, player, accordion) → ailv-ui-widgets, plus ailv-ui-platform-picks for library names and setup gates. Mobile app build → ailv-ui-mobile. Form inputs, dropdowns, menus → ailv-ui-forms. Dialog and form buttons → ailv-ui-buttons. Page behavior and states → ailv-ui-behavior. Headers and navigation → ailv-ui-nav. Images, heroes, banners → ailv-ui-images. Accessibility audit → ailv-ui-a11y. Skip everything else. New codebase only: the house stack wins (see the bank map).

## Checks

- only matched skills are read
- whole area never copied at once
